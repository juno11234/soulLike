#  Soul_Like_Project
 ## 프로젝트 개요 
본 프로젝트는 3인칭 액션 게임으로 **Behaviour Tree**룰 이용하여 공격 템포를 조절할 줄 아는   
**복잡한 몬스터 AI**를 구현하는 것을 목표로 진행하였습니다.


##  개발 환경

>  개발 인원: 1인  
개발 기간: 2025.11.10~2025.11.30  
형상 관리: Github Desktop    
게임 엔진: Unity 6000.0.56f1   
IDE: Rider 2025.2.1

## 핵심 구현 내용
###  1. **Jenkins를 활용한 빌드 자동화**
  * 빌드 과정에서의 실수와 소요 시간을 줄여 원활한 빌드 테스트 환경 구축경험
  * Guthub의 Repository와 연결되어 1시간마다 수정사항을 확인하고 Editor폴더 안에 Build 함수실행
###  2.   **이벤트 기반 MVVM 구현**
  *  MVC 패턴 보다 낮은 의존성으로 잦은 UI 및 데이터 수정에 대응가능
  *  감시하는 대상의 값이 바뀌면 이벤트를 발송하는 Observable<T> 클래스 구현
###  3. **Behaviour Tree 구현**  
  *  상태가 늘어나면 전이 조건이 기하급수적으로 늘어나는 상태 패턴 대신 항상 트리구조를 유지하는 행동 트리 구현
  *  코드 가독성과 구현 편의성을 우선시 한 재귀 방식으로 Evaluate를 호출하여 노드를 순회

##  이슈 해결사항  
###  1.  **콤보가 끊기는 버그**
  *  **문제:** 적AI가 콤보 공격 도중 플레이어가 공격사거리를 벗어나면 진행하던 콤보를 마무리 하지않고 강제로 끊김
  *  **원인:** 하나의 가지에 시퀀스가 2개가 이어질시 앞에 시퀀스에서 실패하면 뒤에 실행중이던 시퀀스도 바로 끊김
  *  **해결:** 인덱스로 현재 실행중인 자식을 기억하고 다음 프레임에서 아직 Running중이라면 해당 인덱스에서 이어서 시작
###  2.  **걷기 애니메이션 재생 버그** 
  *  **문제:** 적 애니메이션에 Vertical 매개변수가 1 이되어 움직임이 없어여하는 상황에서도 걷기 모션 재생
  *  **원인:** 추격노드에서 매개변수를 0으로 만드는 로직이 셀렉터의 우선순위에 막혀 실행되지 않음
  *  **해결:** 애니메이션 및 NavMeshAgent 초기화를 담당해주는 Cleaner노드를 만들어 사용
